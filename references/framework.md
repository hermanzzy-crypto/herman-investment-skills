# HERMAN INVESTMENT — 五维框架清单（原始手写版）

> 这是框架的"清单形态"，分析时按 SKILL.md 的执行协议跑；本文件用于快速对照检查项。

## ① 供求关系（商业模式好不好）
- 供给方：竞争对手有哪些？各自市场份额？是否龙头？是否有核心壁垒？壁垒多强？
- 需求方：需求方有哪些？国内/海外各占多少？是否有明确订单？
- 供求评判：供大于求还是供小于求？是否有定价权？过去 1–3 年是否成功涨价？涨价后对订单与势头的影响？

## ② 产业链视角（调用 serenity-skill）
- 先排产业链层级、再排公司；找最难扩产的稀缺卡点层。

## ③ 财务健康度（短期和长期）
- 现金含量 = 经营现金流 / 归母净利（≈1 健康；持续 <0.5 警惕）
- 资产负债率 + 有息负债结构 → 警惕"短债长投"
- 应收/存货周转 → 营运资本是否吞噬现金（增收不增利）
- 利息保障倍数、商誉、合同负债（在手订单代理）

## ④ 未来潜力（价值投资）
- PE/PB/PS/PEG + 历史估值分位 + 同业对比
- ROE/ROIC（>15–20%、不靠高杠杆）
- 前瞻 PE vs 当前 PE；A+H 看 AH 溢价
- 内在价值 = DCF；安全边际
- 低负债
- ⚠️ 好公司 ≠ 好投资（贵了也是差投资）

## 投资信仰（三维博弈 · 择时）
- 维度一：概念火不火（热度/关注度）
- 维度二：是否足够多人相信（共识/参与广度）
- 维度三：是否有资金流入（真金白银）
（三维指标表见 data-sources.md）

## 卖出纪律 + 买入时点
- 买点：用三维博弈看时点；别在过热/散户暴增/杠杆暴增时追高。
- 卖点：逻辑破坏 / 北向转减持（顶背离）/ 放量滞涨 / 估值透支 / 现金流恶化。

## 证据分级原则（铁律）
- 每个结论标 强（财报/公告/订单/专利）/ 中（媒体/研报）/ 弱（传闻/情绪）。
- "生态伙伴 / 洽谈 / design win" ≠ "确认订单收入"。
- 教训：英维克"英伟达百亿订单" = 弱证据（官网查无、第一财经质疑、NDA 不披露、合同负债不大）。

## 综合判断：接盘动力 vs 危险信号
- 🟢 还能涨：热度升 + 户数温和增 + 两融/北向净流入 + 量能放大 + 估值未极值。
- 🔴 危险（你可能是接盘侠）：户数暴增 / 北向机构减持 / 放量滞涨 / 融资见顶 / 龙虎榜分歧 / 估值极值。
