# HERMAN 五维检查清单

执行与证据边界以 [SKILL.md](../SKILL.md) 为准，财务和估值公式见 [研究协议](research-protocol.md)。

| 维度 | 关键检查 |
|---|---|
| 供求/商业模式 | 供需、竞争、客户/地区、定价权；拆解价格/销量/组合/并表/特殊收益 |
| 产业链卡点 | 先层后公司；替代/认证/有效供给约束；产品阶段→收入→现金的证据链 |
| 财务健康 | 现金转换与TTM、营运资本周转/减值、可动用现金、债务期限及资本开支 |
| 长期价值 | 归母/扣非/正常化、ROE/ROIC来源、新增资本回报、管理层资本配置 |
| 安全边际 | 同口径比较、前瞻EPS重算、情景/反向估值、现金回报和证伪条件 |

情绪独立：热度、共识/拥挤、资金与价格承接。户数、融资和季度托管持仓均须注明统计日、披露日与覆盖范围，不能直接推断投资者身份、强平、出清或下一日涨跌。

每项关键判断留证据（事实/公司口径/预测/测算/推断）、主要风险、证伪条件和下一验证。研究排序不等于交易优先级，相对胜出不等于绝对安全边际；缺资料允许暂不评分。
