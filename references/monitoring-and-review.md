# 跟踪与复盘：每次更新接得上前一次

用于连续跟踪、条件观察、公告/事件分析与复盘。技能不默认设置运行窗口、发送对象或交易触发器。

## 研究与条件分开

区分值得研究、价值条件通过、进入观察价、价格触发且确认。价值未复核仍排研究优先级、证据缺口和复核时点；不能因技术突破升级，也不能永久滚动“研究未完成”。

观察价绑定盈利假设、估值口径、确认/失效条件。分别考虑价格回落盈利不变、盈利兑现上修、价格和盈利同时下修；进入旧价区不自动叫便宜。

已有长期持仓与短期观察各自评估；短期承接弱不独立证明生意变坏，长期看好也不取消仓位与现金约束。

## 条件状态

保留原条件、设立日、依据、确认标准、失效标准、有效期/复核事件、最新证据和状态：未触发 / 盘中触发未确认 / 确认 / 失效 / 到期 / 不可判定。

未取得收盘或其他预定确认数据，不把盘中越线写成确认。确认、失效、到期或假设变化后合理替换；修改展示旧条件、理由和新条件，不随价格无解释上移目标。价格已高于某位时用“守住/回踩”，不能仍写“向上收复”。

只突出改变判断的新证据；稳定财报和技术指标放底稿。算法资金降权，不用指标数量制造确定性。

## 公告与事件

记录官方渠道、检索区间、截止、标题/原文及是否旧事进展。核查失败或覆盖不足写“不完整”，不能写“无公告”。

按事实→盈利/现金/供需/风险溢价传导→预期基准→短期/长期影响→下一验证分析。无可靠预期基准就写不可判断；没有市场/行业对照与足够事件证据，不能确认当日涨跌由公告驱动。

订单额对照营收、利润、履约周期、毛利和执行条件；担保额度不等于已提款融资。利好不保证股价上涨，强证据证伪旧逻辑时优先复核价值。

解禁核对可售起始交易日、投资者类别、股数、总股本/流通股比例及成交量。基石、大股东、Pre-IPO分别统计，潜在可售不等于实际抛售。

事件研究预先定义样本和窗口，保留缺失样本，统一复权并对照市场/行业；记录财报、并购、指数变化等混杂因素。区分事前预期和事后表现，少量挑选案例不能证明“解禁必跌”、因果或稳定概率。

## 交付与停止

一份锁定底稿派生正文/表格/图，核对价格、日期、口径、条件状态和文字方向。存在明确授权的发送流程时，只有成功交付的版本进入已发送条件；失败草稿不覆盖上一已交付状态。

名单、运行窗口、有效延迟和发送渠道属于具体任务配置，不把某次日报的分钟窗口、五只股票、卡片样式或账户路径变成通用研究规则。

接口有限重试后切换可靠源，核心仍缺就交付边界。任务有硬截止时按配置停止，不用旧快照补发当前结论。工作接近一小时先评估剩余问题是否改变判断，缩减非关键补搜并交付有效结果。

## 复盘

记录原假设→当时可得证据→后来事实→判断/数据/执行哪环出错→下一次具体改法。涨跌不能独立评价研究质量，未完成的工作不能记成完成。

择时校准先固定信号、确认标准、观察期限、入场基准和指数，再统计触发/未触发、相对收益、最大有利/不利波动与费用。D+1/D+3不验证长期价值；小样本只报个案，样本增加也要检查选择偏差、重叠、独立性和样本外表现，任意样本数量门槛不证明稳定胜率。
