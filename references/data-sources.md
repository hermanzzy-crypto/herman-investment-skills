# 数据源 playbook（akshare 接口 / 方法）

接口清单是收集入口，不保证当前版本或网络可用。✅仅指编写时曾可获取，需检查本次响应日期、字段、单位和覆盖范围；抓取时间不等于行情、报告或持仓时点。核心结论核对官方原文。

## 称重机（五维）核心数据

| 维度 | 要什么 | akshare 接口 / 方法 |
|---|---|---|
| 行情/市值/PE | 现价、市值、52周、换手 | 交易所/可靠行情源；`stock_comment_em`仅作聚合交叉检查，主力成本为模型值 |
| 财务三表 | 营收/净利/毛利/净利率/ROE/负债/现金流 | `stock_profit_sheet_by_report_em`、`stock_balance_sheet_by_report_em`、`stock_cash_flow_sheet_by_report_em`（symbol=SH/SZ+code）✅ |
| 营运资本 | 应收/存货/合同负债/货币资金 | `stock_balance_sheet_by_report_em`（ACCOUNTS_RECE / INVENTORY / CONTRACT_LIAB / MONETARYFUNDS）✅ |
| 前瞻PE/评级 | 署名EPS预测、评级样本 | `stock_research_report_em`（字段年份随数据变化；用当前价格与对应EPS重算，不沿用旧价PE） |
| 十大流通股东 | 实控人/北向/社保/QFII | `stock_gdfx_free_top_10_em`（symbol=sz/sh+code, date=季末）✅ |

> 现金转换代理=同期NETCASH_OPERATE/PARENT_NETPROFIT；毛利率核对收入与成本科目。净利/期末净资产不是披露加权ROE。负债率=总负债/总资产，不等于有息负债率。详细期间、TTM和估值公式见 [研究协议](research-protocol.md)。

## 投票机·维度一：概念火不火（热度/关注度）

| 指标 | 衡量什么 | 数据源 | 解读阈值 |
|---|---|---|---|
| 概念板块涨幅/排名 | 概念相对大盘超额、是否领涨 | `stock_board_concept_name_em` + `_hist_em` 🟡 | 跑赢沪深300、居涨幅榜前列＝火 |
| 换手率 | 博弈激烈度 | `stock_zh_a_hist`（含换手率列）/ `stock_comment_em` ✅ | 对照自身历史、可比公司与流通盘，固定阈值不普适 |
| 东财人气榜排名 | 平台关注度 | `stock_hot_rank_em` 🟡 | 关注排名不证明实际散户买入 |
| 千股千评·关注指数 | 市场参与意愿 | `stock_comment_em` 🟡 | 关注指数/参与度上行 |
| 近一月研报数 | 卖方关注 | `stock_research_report_em` ✅ | 署名报告发布频率不代表机构实际买卖 |
| 机构调研次数 | 机构关注 | `stock_jgdy_detail_em` 🟡 | 调研机构数激增 |
| 舆论/搜索热度 | 散户舆论温度 | WebSearch 新闻数 / 百度指数 ✅ | 新闻量、搜索量陡增 |

## 投票机·维度二：是否足够多人相信（共识/参与广度）

| 指标 | 衡量什么 | 数据源 | 解读 |
|---|---|---|---|
| 股东户数变化 | 参与广度 | `stock_zh_a_gdhs_detail_em` ✅ | 参与广度/拥挤线索，不能单独识别散户或机构，更不能确定涨跌 |
| 融资余额/买入占比 | 杠杆信仰 | `stock_margin_detail_szse` ✅ | 融资余额/流通市值上行＝杠杆在信 |
| 研报"买入"占比 | 卖方共识 | `stock_research_report_em` ✅ | 仅代表所收集卖方样本；有覆盖/选择偏差，不能代替全市场共识 |
| 公募持仓家数变化 | 机构信仰 | `stock_fund_stock_holder` 🟡 | 持有基金家数上升 |
| 北向/社保/QFII（季度） | 聪明钱信仰 | `stock_gdfx_free_top_10_em` ✅ | 对应统计期披露的持仓变化，不是当前买卖或真实成本 |
| 估值分位(PE/PB) | 历史定价位置 | 同口径历史估值序列 | 需区间和异常值处理，研报前瞻PE不能代替历史分位 |

## 投票机·维度三：是否有资金流入（真金白银）

| 指标 | 衡量什么 | 数据源 | 解读 |
|---|---|---|---|
| 龙虎榜净买入+游资席位 | 游资点火 | `stock_lhb_stock_detail_em` / `_yyb_detail_em` / `_date_em` ✅ | 仅上榜披露范围；不能等同全部机构交易，买卖榜同席位注意去重 |
| 融资余额净增 | 杠杆流入 | `stock_margin_detail_szse` ✅ | 单日/单周融资净增 |
| 互联互通汇总 | 市场参与背景 | 交易所及聚合接口 | 核查当前披露制度；成交额不等于净买入，全市场不代表个股 |
| 港股南向(CCASS) | 南向加减仓(港股) | HKEX/CCASS/互联互通披露（按当期规则核查） | 托管参与者持仓非最终受益人；变化不直接识别交易动机或成本 |
| 主力/超大单净流入 | 资金流(推断) | `stock_individual_fund_flow` ⚠️ | 推断非真身，仅作情绪参考 |
| 大宗交易折溢价 | 机构进出 | `stock_dzjy_mrtj_em` 🟡 | 真实成交价；折价不直接识别最终机构身份或动机 |
| 量能 | 资金活跃度 | `stock_zh_a_hist`（成交额）✅ | 活跃度不是净流入；盘中累计量须与同一时刻比，不能直接比昨天全天 |

## ⚠️ 6 个数据陷阱（不懂会被误导）

1. **"主力资金流向"是按单子大小推断的伪身份**——量化/游资拆单都会混进"大单"，≠真机构。
2. **互联互通披露制度会变化**：2024年调整后不可沿用旧版个股日度接口假设；本次需核查官方实际覆盖、日期与成交额/净额区别。季度香港中央结算是托管口径，不能当逐日机构交易。
3. **股东户数不能直接识别身份**——增加可能提示参与扩散，需结合价格、估值和其他证据；既非必涨也非必跌。
4. **持仓指标往往滞后**——同时记录统计日与披露日，不能用季度数据解释当日行为。
5. **反身性双向**——指标向上自我强化，信号一裂同样猛地反向。
6. **"主力成本"是模型弱信号**——平台按成交/筹码模型估算，算法未经核实时不断言具体公式。它不是真实已知的某机构成本，价格在其下方也不证明特定机构浮亏。优先使用下方披露数据，并限制身份、成本及覆盖范围的解释。

## 附录：判断"谁在什么价位 / 成本"用哪些数据（按可靠度）

| 信号 | 可靠度 | 为什么硬 | akshare 接口 |
|---|---|---|---|
| 龙虎榜席位买入额/价 | 🟢强（仅上榜日）| 真实披露席位与金额，未必有成交均价，不是全部交易；两榜同席位去重 | `stock_lhb_stock_detail_em` / `_yyb_detail_em` |
| 大宗交易价格 | 🟢强 | 真实成交价 + 折溢价 | `stock_dzjy_mrtj_em` |
| 定增/配股价 | 🟢强 | 该次发行认购价，非所有持仓综合成本 | 巨潮公告 / `stock_qbzf_em` |
| 股东户数变化（季度）| 🟢强 | 真实户数，不能独立识别散户进出或成本 | `stock_zh_a_gdhs_detail_em` |
| 北向/机构持仓（季度）| 🟢强 | 统计期/披露范围内持股，托管人不等于最终受益人，未披露成本| `stock_gdfx_free_top_10_em` |
| 筹码分布（平均成本/获利比例/成本集中度）| 🔴弱 | 仍是模型估算，不提升为真实成本 | `stock_cyq_em` |
| **主力成本 / 主力资金流向** | 🔴弱 | **算法推断、非真身、各平台不一** | `stock_comment_em` / `stock_individual_fund_flow` |

> **铁律**：判断"谁在什么价位/成本"，优先信 **龙虎榜席位、大宗交易、定增价、股东户数、北向机构持仓** 这些披露数据（仍需限定覆盖与身份）；**"主力成本 / 主力资金"只作弱参考，绝不当事实下结论。**

## 环境坑速记
- 港股报价 akshare 偶发 `RemoteDisconnected`，重试一次或改 WebSearch。
- `stock_a_indicator_lg` 在部分 akshare 版本不存在；聚合PE仅作交叉检查，用有时点的价格与同口径盈利重算。
- A股 EM 三表 symbol 格式：`SH`/`SZ` + 代码（6开头=SH，其余=SZ）。
- TTM盈利很小或亏损时PE解释力弱，需检查正常化盈利和情景，不直接用前瞻PE消除风险。

## 工具回退与完成边界

- `pull_stock_snapshot.py`仅收集A股资料，输出各节错误、日期和缺口；不证明完成五维分析。港股直接查HKEX、招股书/中报与可靠行情源。
- 官方原文优先，聚合接口交叉检查。接口有限重试后切换独立来源；仍不可得写缺口，未查到不等于没有。
- 切换源后重核币种、复权、股本、统计期及单位。行情缺日期或最新日融资记录缺失时，不冒充当日数据、不补0。
- 不依赖个人机器路径或未打包的脚本；不把历史“已实测”当当前可用性承诺。
